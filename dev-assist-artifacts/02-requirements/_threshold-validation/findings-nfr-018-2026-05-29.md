## Aggregate verdict: **ACCEPTED-WITH-CAVEATS**
The per-tier numeric thresholds (**≥1,522 / ≥753 / ≥200**, NIST-derived) are **LOCKED** — unanimous keep, math independently re-verified (n=⌈z²·p(1−p)/d²⌉ → 1,522 / 753 / ~183→200). The six binding caveats refine the gate **mechanism**, **track scope**, and **framing** — not the numbers.

## Binding refinements (each threads into NFR-018 / FR-029 / sampling-design.md / code)
1. **Corpus-power gate ≠ detector-regression gate (tool-builder-detector).** NFR-018's hard gate is a **corpus power floor** — "does the corpus hold ≥target positives in this committed cell?" It is **count-based, monotone, and NOT PR-flaky** (positives only grow; no sampling jitter). It is DISTINCT from the **detector A/B regression gate (FR-002)**, which compares two systems and MUST use a **paired McNemar / discordant-pair test** (not CI-overlap) with a stated minimum-detectable-regression per tier, FDR-corrected or main-effects-hard / interactions-advisory to bound false-alarm PR blocks, phased in via observation mode. → Clarify the two-gate distinction in NFR-018 + sampling-design.md; `power.py` ships `required_discordant_pairs()` for the FR-002 gate.
2. **Track-specific power statement (tool-builder-anonymizer).** The 1,522/753/200 tiers are sized for **detection recall** (p≈0.95–0.99). Anonymization / pseudonymization / RRS cells (DC-06/07/08) have a **different denominator** (paired personas / candidate set |C|) and operating point (p≈0.1–0.5), so they need a **parallel power ladder** sized at the re-id operating point (e.g., d=±3pp at p=0.3 → ~897 pairs/cell; p=0.1 → ~385). → NFR-018 detection-recall tiers **scope to the detection track**; a forward seam for the RRS/utility power ladder is documented now and fully built when S3/S4 scorers land.
3. **Non-strippable external-validity caveat (acad-deid-clinical, priv-eng-runtime, dpo).** Because synthetic cells are *fillable by generation*, a tight committed-cell CI is "precision on a synthetic distribution," not external validity. Every published per-cell metric MUST carry a **non-strippable** synthetic-provenance + external-validity caveat and MUST NOT be citable as a standalone recall claim absent the real-data correlation slice (FR-027). → Add the caveat field to `DesignProvenance` (mirrors the RRS non-strippable-caveat pattern, FR-009); cross-reference FR-027 from NFR-018.
4. **Curated, not Cartesian (priv-eng-batch, researcher-industry).** The committed 2-way set MUST be an **editorially curated, balanced D-optimal fraction** with its **cardinality + projected positive budget published** in sampling-design.md — not a language×type×domain Cartesian explosion (which would flip batch-eng to REVISE-LOOSER and blow the industry-lab compute budget). → Reinforces the design's forced-skeleton + balanced-fraction construction; publish the committed-cell count + projected corpus growth at the dry-run checkpoint.
5. **Coverage vs depth for adversarial/oracle (agentic-redteam).** The adversarial-type×entity-type interaction and the oracle/payload export (FR-017/018, DC-10) are best gated on **coverage** (≥1 of every attack×type combination) + recognition-accuracy; the n≥753/1,522 **depth** gate scopes to cells backing a *published robustness claim*. → sampling-design.md distinguishes a coverage gate (presence) from the power (depth) gate.
6. **Long-tail honesty (acad-deid-legal).** A ≥200 cell carries a ±~3pp band that MUST always be displayed (never collapsed to a point). → Already implied by NFR-002/AX-003 (no bare point scores); reinforced in FR-029 power-table output.
