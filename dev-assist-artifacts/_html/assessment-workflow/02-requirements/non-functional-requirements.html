Architecture (locked). eval-data OWNS sampling + observability + reporting; pii-rate-elo CONSUMES (extend, do NOT rebuild the engine/metrics). Each NFR carries: id · title · a QUANTIFIED threshold (number + unit) OR a boolean-auditable criterion · a measurement method · the axiom / precondition it serves. "Boolean-auditable" = a single predicate a CI job (or a named reviewer) can assert true/false. Where a number is grounded in code, the file + symbol is cited so Design/Dev can re-confirm.

Proposed axiom — AX-pii-anon-005 (recorded here for PO confirmation)

AX-pii-anon-005 (Pre-registered / reproducible assessment). No published metric ships without all of: (1) a confidence interval with the interval-selection method named; (2) a paired test backing every system-vs-system claim, under an explicitly declared multiplicity family — two inference families: exploratory per-cell uncorrected (labelled, never a headline) vs confirmatory pairwise Holm-Bonferroni with the family size stated (declaration is in the axiom/report text, not only in code — "reviewers will ask"; INT-01/INT-02); (3) a convergence statement reported as achieved max-RD ± 2RD (95%) with the rounds/stopping rule stated, never an extrapolated round count (G4; INT-02); (4) provenance sufficient to reproduce the run from the manifest ({dataset_version, record_count, schema_fingerprint, seed, stage, code_commit, toolchain} + file-level provenance); (5) a non-strippable synthetic-only / anti-anonymity caveat on every metric (AX-001/003); and — for leaderboard/published entries — (6) contamination disclosure: a per-system contamination_status with unknown rejected/flagged, plus a signed attestation that held-out labels were not exposed (INT-03's 6th element).

Enforcement scope is run-type-bound (the §4 universality tension, resolved): the full AX-005 bar binds the leaderboard-submission / filing-grade run-types; smoke / dev runs suppress CI + p-value emission entirely (UC-20) — there is no un-rigorous number to mis-cite because there is no number — which satisfies both "the exploratory run is where people get sloppy" (INT-02) and "universal enforcement makes teams avoid the formal mode" (INT-05).

Status: PROPOSED — confirmed as "the right bar" by all interviewees who reached probe #17, with the two sharpenings above (multiplicity-family-in-text; 6th contamination element) and run-type-scoped enforcement. The NFRs in this document are the testable operationalization of this axiom. Inherited binding axioms unchanged: AX-001 (synthetic-only) · AX-002 (deterministic/seeded/byte-reproducible) · AX-003 (stated power — n + CI) · AX-004 (anon vs pseudo, separate metric families).

A. Statistics-core integrity (the SHOWSTOPPER precondition P1)

  • NFR-019 — Run path uses ONLY the audited eval-data statistics core; significance.py quarantined. Threshold (boolean-auditable): zero statistical quantities on the assessment run path are produced by pii-rate-elo/analysis/significance.py::SignificanceTester; every CI and every paired test is computed by eval-data stats/intervals.py (wilson_interval / clopper_pearson_interval) and stats/paired.py (mcnemar_exact / mcnemar_chi2 / paired_bootstrap_recall_delta). The assessment preset sets analysis.run_significance_tests: false (it is read at cli.py:240, which instantiates SignificanceTester() at cli.py:242); a CI guard asserts the assessment code path never imports/instantiates SignificanceTester. Measure: CI gate (blocking): import-graph / call-graph static check on the assessment entrypoint asserting SignificanceTester is unreachable AND a config assertion run_significance_tests == False — these two CI predicates ARE the gate (green requires no human). Reviewer audit is a secondary, non-gating corroboration only. Serves: P1 (SHOWSTOPPER); AX-pii-anon-005 (CI + paired test).

  • NFR-020 — Zero approximated statistics on the run path (fabrication ban). Threshold (boolean-auditable): zero occurrences on the run path of the fabricated forms verified at HEAD — se = metric_value*(1-metric_value)/100 + np.random.normal(...) (significance.py:205-206), n_approx = 100 / pooled_sd = 0.1 / z_stat = difference*sqrt(n_approx)/0.05 (significance.py:271-281) — i.e. no standard error from a hardcoded constant instead of n, no Gaussian noise as a substitute for resampling, no McNemar that never sees a discordant-pair (b, c) count. Every paired test on the run path consumes real discordant-pair counts; every bootstrap resamples pair indices. Measure: CI gate (blocking): grep-based forbidden-pattern lint over the declared run-path module set against a committed regex list — the three verified fabrication signatures { *(1-*)/100 , np.random.normal , (n_approx | pooled_sd\s*=\s*0\.1 | sqrt\(n_approx\)/0\.05) } — pass condition = zero matches. Reviewer diff of the two implementations is a secondary, non-gating corroboration. Serves: P1; AX-pii-anon-005.

  • NFR-021 — Seeded LOCAL-RNG determinism for all resampling (no global RNG on the run path). Threshold (boolean-auditable): every bootstrap / resample on the run path drives a local random.Random(seed) instance and never the module-global RNG or numpy global RNG; two runs with the same seed are byte-identical in their resampled outputs regardless of ambient random.seed(...). (stats/paired.py::paired_bootstrap_recall_delta already owns a local random.Random(seed) at L140; the fabricated significance.py path uses np.random global RNG — banned by NFR-019/020.) Measure: same-seed re-run byte-equality test for every resampled statistic + static check for np.random. / bare random. global calls on the run path. Serves: P1; AX-002; AX-pii-anon-005.

  • NFR-022 — Integer-guarded interval inputs (no fractional Bernoulli counts). Threshold (boolean-auditable): every CI on the run path is computed from honest integer (k, n) Bernoulli counts with 0 ≤ k ≤ n; fractional/partial counts and bool inputs are rejected with TypeError/ValueError (the reidx-02 guard stats/intervals.py::_require_int_counts, L39-51, shared by wilson_interval and clopper_pearson_interval). No interval is ever derived from a smoothed/blended/partial count. Measure: the existing reidx-02 guard tests stay green + a run-path assertion that interval inputs are int. Serves: P1; AX-003.

B. Confidence intervals on every metric (AX-003 / AX-005 element 1)

  • NFR-023 — CI on 100% of published metrics, with a deterministic interval-selection rule. Threshold: 100% of published metrics carry {n, ci_low, ci_high, method}; zero bare point estimates. The method is assigned by a deterministic, pre-registered selection rule: proportions → Wilson (default); boundary (point estimate at 0 or 1, i.e. k ∈ {0, n}) → Clopper-Pearson (this boundary clause is the load-bearing, statistically-mandated branch — it fixes Wilson's degenerate behaviour at p̂ = 0|1); small-n (n < small_n_cutoff, where small_n_cutoff is a single integer RECORDED in the manifest + pre-registration, committed default small_n_cutoff = 15 — R10 DIVERGED edit: lowered from 30 → 15 toward the Wilson-robust-to-n≈10 zone, since both the cited binomial-CI literature [Brown/Cai/DasGupta 2001; Wikipedia] AND both R10 personas agree the n-based Clopper-Pearson switch is over-conservative and that the literature endorses no specific integer; the value remains R10-DIRECTIONAL / real_user_needed: true pending a real ACL/PETS/de-id reviewer in Pass-2, never a silent constant) → Clopper-Pearson; paired differences → paired-bootstrap. Measure: report linter asserts every metric row has a non-null CI with method ∈ {wilson, clopper-pearson, paired-bootstrap} whose value equals the method the recorded small_n_cutoff prescribes for that row's (k, n) class — a method inconsistent with the recorded cutoff fails (CI-blocking). Serves: AX-003; AX-pii-anon-005 (element 1); UC-17(a), UC-23(a). (real_user_needed: true on the small_n_cutoff integer — the boundary clause and the determinism/manifest-recording contract are firm; only the n-switch integer awaits a real reviewer.)

  • NFR-024 — CI scope is conditional-on-this-sample; corpus-draw variance declared. Threshold (boolean-auditable): every reported CI is labelled scope: conditional-on-this-sample; corpus-draw (seed-to-seed) variance is either measured (len(seeds) ≥ MIN_SEEDS, committed MIN_SEEDS = 3 — reconciled with FR-043's INT-02 3-seed floor; R10 may relax to 2 with recorded rationale — with Kendall-τ rank stability reported) or explicitly flagged seed_variance_scope: single-seed → carried to the report as rank-volatility: UNMEASURED. No CI is presented as if it captured resampling variance it did not measure. Measure: presence of scope on every CI + presence of either the len(seeds) ≥ MIN_SEEDS (==3) + Kendall-τ block or the single-seed flag, asserted by the report linter (CI-blocking). Serves: AX-003; AX-pii-anon-005; UC-17(e), UC-23(d).

  • NFR-025 — Census runs are descriptive (no CI) unless a super-population target is declared. Threshold (boolean-auditable): a full-corpus run (UC-19) labels its metrics exact-on-corpus / descriptive-census with NO CI by default; CIs are retained only when the report explicitly declares the inferential target is a super-population (future inputs), not the fixed corpus. Measure: run-record inferential_target ∈ {exact-on-corpus, super-population} + linter (census + no declaration ⇒ CI fields must be absent). Serves: AX-003 (honest n-semantics); UC-19.

C. Paired tests + multiplicity (AX-005 element 2)

  • NFR-026 — Paired test required for every system-vs-system claim. Threshold (boolean-auditable): every confirmatory pairwise system claim carries a McNemar verdict (exact binomial / Edwards continuity-corrected χ², stats/paired.py) AND a paired-bootstrap recall-delta CI. A directional claim with no paired test is rejected (not merely warned). Measure: report linter — every pairwise row has a McNemar p-value + a paired-bootstrap delta CI (CI-blocking). Serves: AX-pii-anon-005 (element 2); UC-17(b), UC-23(b); closes the "delta within noise, no significance test" rejection vector (INT-01/02).

  • NFR-027 — Two declared inference families with Holm-Bonferroni and stated family size. Threshold (boolean-auditable): the report declares exactly two inference families — exploratory (per-cell, uncorrected, labelled as such and never a headline claim) vs confirmatory (pairwise, Holm-Bonferroni corrected, with the family size = #pairs × #metrics in the confirmatory set printed). The family declaration is carried as a structured inference_families block (the report prose renders from it) present in both the report payload and the pre-reg payload. Measure: linter asserts the inference_families block carries exactly the two labels {exploratory, confirmatory}, every confirmatory claim carries a Holm-adjusted decision, and confirmatory.family_size is an integer == #pairs × #metrics in the confirmatory set (computed, not free-typed); a missing block in either payload, only-one-family, or family_size ≠ the product fails; pre-reg↔report parity check (UC-18) (CI-blocking). Serves: AX-pii-anon-005 (element 2, sharpening a); UC-17(a), UC-23(b).

  • NFR-028 — Ranks gated by the paired-test verdict (ties greyed). Threshold (boolean-auditable): in the leaderboard, any system pair whose difference is not significant post-Holm-Bonferroni is grouped/greyed as a statistical tie; no rank out-runs its paired evidence. Measure: report linter — for every adjacent rank pair, a significant Holm decision exists OR the pair is rendered as a tie (CI-blocking). Serves: AX-pii-anon-005 (element 2); UC-23(b); STATS-07.

Measure: every cell carries a power_class with target_n reproduced from its triple + a named shortfall on every under-tier cell; PowerMatrix.verdict() present in the manifest; no cell unclassified or silently under-tier. Serves: P3; AX-003; UC-16.

  • NFR-036 — Shortfall expressed in REALIZED positive counts, per (entity-type × language) cell. Measure: linter asserts each under-tier cell has an integer realized_positive_shortfall + the non-strippable binding; reuses scripts/lattice_audit.py::deficits (returns observed + deficit per committed cell).   • NFR-037 — UNDER_SAMPLED vs CORPUS_LIMITED vs EMPTY distinction surfaced (fixable vs irreducible). A CORPUS_LIMITED cell is never labelled as merely under-sampled. Measure: classification check that compares cell realized positives to both the sample draw and the full-corpus positive total (lattice_audit.audit_positives over the full corpus) (CI-blocking). Grounded in scripts/lattice_audit.py::audit_positives ("single streaming pass… key set bounded by #committed-cells, not the cross-product") and scripts/benchmark_throughput.py::reservoir_sample (Algorithm-R single-pass, seeded under SEED_BENCHMARK).
