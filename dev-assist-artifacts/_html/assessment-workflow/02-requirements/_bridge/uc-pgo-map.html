Vocabulary remap (project framing). PGO = a persona's (Persona · Goal · Outcome) workflow triple; UC = Evaluation Scenario. This bridge is the forward/reverse navigation map between the two, plus an orphan scan. It is the contract Requirements (FR-030+, NFR-019+) traces back through: every FR/NFR must serve a UC, every UC must serve ≥1 PGO, every MUST-tier PGO must be served by ≥1 UC.
