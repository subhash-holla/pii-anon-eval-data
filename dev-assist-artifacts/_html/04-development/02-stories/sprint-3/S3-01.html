2. Goal

7. Acceptance criteria (Given/When/Then from FR-010)

Given a consumer-supplied adversary object exposing adversary_id, deterministic, and attack(targets, candidates, candidate_set_size), When the scoring core type-checks it against the Adversary Protocol, Then it is accepted as a pluggable adversary and its adversary_id is available for version-pinning ("vs adversary@version"). And Given the tier3 corpus substrate, When assemble_paired_set runs, Then it deterministically yields aligned (targets, candidates) with target_id == persona_id ground-truth links and |C| honored. Negative test: an object missing any of the three members is NOT an Adversary (isinstance False); assemble_paired_set skips records lacking the tier3 substrate.

8b. Implementation spec (authoritative — build to this)

Pure-stdlib (NFR-004). Frozen dataclasses. Type hints everywhere; ruff/mypy --strict clean.

# scoring/adversary/base.py
ADVERSARY_PORT_VERSION = "adversary-port-v1"

@dataclass(frozen=True)
class Persona:                      # the REAL side
    persona_id: str                 # == record_id (stable)
    record_id: str
    quasi_identifiers: tuple[tuple[str, str], ...]   # ((entity_type, value), ...) sorted
    behavioral_signals: dict        # tier3_evaluation.behavioral_signals (read-only, GOLD)
    source_text: str                # original real text

@dataclass(frozen=True)
class Target:                       # the PSEUDONYMOUS side the adversary attacks
    target_id: str                  # == persona_id of its true source (ground-truth link)
    anonymized_text: str            # e.g. context_preservation.anonymized_pseudonymized
    observed_signals: dict          # RE-EXTRACTED from anonymized_text via signals.py — NOT gold

@dataclass(frozen=True)
class Guess:
    target_id: str
    guessed_persona_id: str | None  # None == abstain (excluded from precision denominator)
    score: float                    # similarity/confidence for ranking

@runtime_checkable
class Adversary(Protocol):
    adversary_id: str               # version-pinned, e.g. "offline-deterministic-v1"
    deterministic: bool
    def attack(self, targets: Sequence[Target], candidates: Sequence[Persona],
               candidate_set_size: int) -> list[Guess]: ...

# scoring/adversary/__init__.py
DEFAULT_CANDIDATE_SET_SIZE = 2500   # documented default sample of the ~159,891 tier3 personas;
                                    # |C| is a first-class parameter — any N <= n_available is valid.

def assemble_paired_set(records, *, candidate_set_size=DEFAULT_CANDIDATE_SET_SIZE,
                        variant="pseudonymized") -> tuple[list[Target], list[Persona]]:
    # 1. filter to records with BOTH tier3_evaluation.behavioral_signals AND context_preservation
    # 2. sort deterministically by record_id; take first min(candidate_set_size, n) as candidates
    # 3. Persona: persona_id=record_id, quasi_identifiers=sorted((a["entity_type"],a["text"]) for
    #    a in annotations), behavioral_signals=tier3_evaluation.behavioral_signals, source_text=text
    # 4. Target: anonymized_text=context_preservation[f"anonymized_{variant}"],
    #    observed_signals=signals.extract(anonymized_text)  ← RE-EXTRACT, never copy gold,
    #    target_id=persona_id (ground-truth link)
