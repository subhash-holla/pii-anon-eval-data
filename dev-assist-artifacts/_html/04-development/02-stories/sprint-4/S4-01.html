8b. Implementation spec (authoritative)

Pure-stdlib (math only). Same integer guard + Interval shape as wilson_interval.

def clopper_pearson_interval(k: int, n: int, confidence: float = 0.95) -> Interval:
    # integer guard IDENTICAL to wilson_interval (reidx-02): reject non-int / bool k,n; require 0<=k<=n
    # n == 0 → return the same n=0 sentinel Interval(nan, 0.0, 1.0, 0, "clopper-pearson", confidence)
    # alpha = 1 - confidence
    # low  = 0.0      if k == 0 else _inv_betainc(alpha/2,       k,   n - k + 1)
    # high = 1.0      if k == n else _inv_betainc(1 - alpha/2,   k+1, n - k)
    # point = k / n
    # return Interval(point, low, high, n, "clopper-pearson", confidence)

Inverse regularized incomplete beta (no scipy):

  • _betacf(a, b, x) — Lentz continued fraction for I_x(a,b) (Numerical Recipes §6.4); fixed max-iter (~200) + 1e-12 tol.
  • _betainc(a, b, x) — exp(lgamma(a+b) - lgamma(a) - lgamma(b) + a*ln x + b*ln(1-x)) * _betacf(...)/a, with the symmetry swap x > (a+1)/(a+b+2) → 1 - _betainc(b, a, 1-x). math.lgamma is stdlib.
  • _inv_betainc(p, a, b) — bisection on [0,1] (monotone in x; ~60 iters → 1e-12). Bisection (not Newton) is dependency-free + robust at the k=0/k=n edges. Fixed iteration count → deterministic (NFR-004).

Reuse Interval + the integer-guard helper from intervals.py (factor the guard out of wilson_interval if it isn't already, WITHOUT changing Wilson's behavior).
