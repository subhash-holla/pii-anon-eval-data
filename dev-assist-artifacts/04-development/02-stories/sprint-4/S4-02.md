## 7. Acceptance criteria (G/W/T from FR-002 / NFR-002)

> **Given** paired (system-A-hit, system-B-hit) booleans over the same gold spans,
> **When** the paired stats run,
> **Then** McNemar (exact binomial + continuity-χ²) over the discordant pairs `(b, c)` yields a statistic + named-method p-value, AND a seeded paired bootstrap yields a recall-difference `Interval` (method "paired-bootstrap").
> **Negative**: `b+c==0` → no-difference (p=1.0); the bootstrap is reproducible for a fixed seed and not driven by the global RNG.

## 8b. Implementation spec (authoritative)

Pure-stdlib (`math` + `random.Random` only). Reuse `Interval` from `intervals.py`.

```python
@dataclass(frozen=True)
class McNemarResult:
    b: int; c: int                       # discordant pairs: b = A-hit & B-miss, c = A-miss & B-hit
    statistic: float
    p_value: float
    method: str                          # "mcnemar-exact" | "mcnemar-chi2-continuity"
    odds_ratio: float | None             # b/c, None if c==0
    def as_dict(self) -> dict[str, object]: ...

def mcnemar_exact(b: int, c: int) -> McNemarResult:
    # n = b+c; if n==0 → statistic 0.0, p 1.0. Two-sided exact binomial:
    # p = min(1.0, 2 * sum(C(n,i)*0.5**n for i in range(0, min(b,c)+1)))  [math.comb]
    # statistic = min(b,c); method "mcnemar-exact"; odds_ratio = b/c or None

def mcnemar_chi2(b: int, c: int, *, continuity: bool = True) -> McNemarResult:
    # n=b+c; if n==0 → 0.0, 1.0. chi2 = (abs(b-c) - (1 if continuity else 0))**2 / n  (clip neg→0)
    # p = erfc(sqrt(chi2/2))   [chi2_sf(x, df=1) closed form; math.erfc]
    # method "mcnemar-chi2-continuity" (or "mcnemar-chi2"); odds_ratio = b/c or None

def paired_bootstrap_recall_delta(pairs, *, n_boot: int = 10000, seed: int,
                                  confidence: float = 0.95) -> Interval:

    # rng = random.Random(seed); for each of n_boot reps resample indices with replacement,
    # recompute Δ over the resample; report [α/2, 1-α/2] percentile interval as
    # Interval(point=observedΔ, low, high, n=len(pairs), method="paired-bootstrap", confidence).
    # SEEDED random.Random(seed) — never the module-global random — for reproducibility (NFR-004).
```

**The bootstrap MUST use `random.Random(seed)`** (a local instance), never `random.sample`/the module
global, so two runs with the same seed are byte-identical (NFR-004). McNemar pairs with the S-PWR
design-time sizer `power.py::required_discordant_pairs` (Lachin) — this is its measurement realisation.
