## 8b. Implementation spec (authoritative)

matplotlib is a LAZY import inside each render function (never at module top); the `reporting` package
+ `reporting.viz` module import cleanly without it. Render fns take THIN inputs (no hard `scoring` import).

```python
def _require_matplotlib():
    try:
        import matplotlib; matplotlib.use("Agg"); import matplotlib.pyplot as plt
    except ImportError as e:
        raise RuntimeError("viz needs the optional 'viz' extra: pip install pii-anon-datasets[viz]") from e
    return plt

@dataclass(frozen=True)
class LeakageEdge:
    source: str; target: str; value: float

def reliability_diagram(result, path: str) -> str: ...   # result: a CalibrationResult-shaped obj (duck-typed: .reliability bins)
def pareto_plot(points, path: str) -> str: ...           # points: Sequence[tuple[float,float,str]] = (residual_risk, utility, label)
def slice_heatmap(power_matrix, path: str) -> str: ...    # delegate to power_matrix.heatmap(path)
def agent_leakage_sankey(edges, path: str) -> str: ...    # edges: Sequence[LeakageEdge]
def coverage_risk_curve(confidences, correct, path: str) -> str: ...  # selective prediction; FR-005 abstention facet
# each: plt = _require_matplotlib(); build figure; plt.savefig(path); plt.close(); return path
```

**Thin inputs (load-bearing, AX-004 + module-boundary):** `pareto_plot` takes `(residual_risk, utility,
label)` tuples — it does NOT import `ParetoPoint`/`scoring`; the CALLER unpacks a `ParetoPoint` into the
two axis values + label. So a viz function structurally cannot fuse the two axes (it plots them as x/y).
`reliability_diagram` duck-types the bins (`.reliability`) so it doesn't hard-import `CalibrationResult`.

**Lazy import (NFR-004):** `import matplotlib` lives ONLY inside `_require_matplotlib`. `reporting/__init__`
re-exports the viz fns via `from .viz import ...` (defining them needs no matplotlib — only CALLING does).
Verify `import pii_anon_datasets.reporting` succeeds with matplotlib absent.

**Deterministic-enough:** PNG byte-equality is NOT asserted (matplotlib embeds timestamps); tests assert
the file is written + non-empty + (where cheap) has a PNG magic header. Do NOT chase pixel determinism.
