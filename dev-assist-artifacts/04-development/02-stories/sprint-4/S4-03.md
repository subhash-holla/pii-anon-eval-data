### Hand-computed reference values (impl NOT trusted — pinned in the tests)

Fixed input (n=8): `conf = [0.05, 0.15, 0.25, 0.35, 0.85, 0.95, 0.95, 1.00]`, `correct = [0,0,1,0,1,1,1,0]`.
Equal-width bins, n_bins=10, `idx = min(9, int(conf*10))`.

- **ECE** = Σ_m (|B_m|/N)·|acc(B_m) − conf_mean(B_m)|
  = `0.125·0.05 + 0.125·0.15 + 0.125·0.75 + 0.125·0.35 + 0.125·0.15 + 0.375·|2/3 − 2.9/3|`
  = `0.00625 + 0.01875 + 0.09375 + 0.04375 + 0.01875 + 0.1125` = **0.29375** (> 0.05 → `meets_reference == False`, reported, not raised).
- **Brier** = mean((conf − correct)²) = `(0.0025+0.0225+0.5625+0.1225+0.0225+0.0025+0.0025+1.0)/8` = `1.7375/8` = **0.2171875**.
- **Perfect calibration** (`conf=[0.25×4, 0.75×4]`, `correct=[1,0,0,0, 1,1,1,0]`): each bin acc == conf_mean → **ECE = 0.0**.
- **Per-entity-class** (`test_nfr_008_calibration_by_entity_class`): PERSON (conf 0.75, 3/4 correct) → ECE **0.0**, Brier **0.1875**; EMAIL (conf 0.90, 0/2 correct) → ECE **0.9**, Brier **0.81** (badly-calibrated class still returns — reported, not gated).
