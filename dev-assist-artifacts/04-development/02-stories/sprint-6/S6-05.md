## 8b. Implementation spec (authoritative — required CONTRIBUTING.md sections)

CONTRIBUTING.md MUST include (the test asserts the load-bearing strings):
- **# Contributing** title + how-to-contribute (fork → branch → PR).
- **## Pull-request template** — the checklist a PR must satisfy (or a pointer to
  `.github/PULL_REQUEST_TEMPLATE.md`): what changed, traced FR/NFR, tests added, provenance.
- **## License compatibility (CC0)** — contributed **data** must be **CC0-compatible** (public-domain
  dedication; no scraped/real PII, no incompatible upstream license); the **code** is **Apache-2.0**.
- **## Provenance & synthetic-only** — every contributed record must be **synthetic** with declared
  provenance (generator/seed/source_type); **no real PII** (AX-001) — the synthetic-only gate.
- **## Deprecation & erratum policy** — how a flawed record / metric / claim is deprecated or corrected
  (an erratum entry + a deprecation window), without rewriting history.
- **## Versioning & releases** — **semantic versioning** + **dated** releases; breaking changes bump major
  + carry a MIGRATION entry.

**Load-bearing invariants:** (1) **FR-025 completeness** — PR template + CC0 checklist + provenance +
deprecation/erratum + semver all present (the test pins each). (2) **CC0/synthetic gate** — the data-CC0
+ no-real-PII requirement is explicit (AX-001).
