## 2. Goal

Ship `src/pii_anon_datasets/leaderboard/store.py` (+ `leaderboard/__init__.py`): an **append-only,
event-sourced** held-out leaderboard store. Each submission lifecycle event (`submitted` / `scored` /
`published`) is appended to a JSONL log, carrying the **content-hash of the prior event** (a hash chain)
so the log is tamper-evident — `verify_chain()` recomputes the chain and detects any mutation. The store
records **scores + config/version attestation + provenance, NEVER the held-out gold labels** (FR-023: the
gold stays undistributed). It never mutates or deletes a prior event. Pure-stdlib; deterministic (no
clock/RNG — events are ordered by a monotonic `seq`, any wall-clock timestamp is an optional
caller-provided payload field, never generated here). Also wire a minimal `leaderboard.main(argv)->int`
(`verify <log>` → `verify_chain`) so S5-05's `pii-anon leaderboard` verb works.

## 7. Acceptance criteria (G/W/T from FR-023 / NFR-014)

> **Given** a leaderboard store backed by an append-only JSONL log,
> **When** submission lifecycle events are appended,
> **Then** each event is content-hash-chained to its predecessor, the held-out gold is never stored
> (forbidden-key reject), prior events are never mutated/deleted, `verify_chain()` detects tampering, and
> the store is deterministic (seq-ordered, no clock/RNG).
> **Negative**: a payload with a held-out-gold key is rejected; a mutated log fails `verify_chain`; there
> is no update/delete API.

## 8b. Implementation spec (authoritative)

Pure-stdlib (`json`, `hashlib`, `enum`, `dataclasses`, `pathlib`, `collections.abc`). NO `time`/`datetime`
(determinism — order by `seq`; a wall-clock timestamp is an optional caller payload field, never generated).

```python
from __future__ import annotations
import hashlib
import json
from collections.abc import Mapping
from dataclasses import dataclass
from enum import Enum
from pathlib import Path

class EventType(str, Enum):
    SUBMITTED = "submitted"
    SCORED = "scored"
    PUBLISHED = "published"

GENESIS_HASH: str = "0" * 64  # prev_hash of the first event

# Held-out GOLD must NEVER enter the store (FR-023). Reject these payload keys.
_FORBIDDEN_PAYLOAD_KEYS: frozenset[str] = frozenset(
    {"gold", "gold_labels", "held_out", "held_out_labels", "answers", "ground_truth"}
)

def _hash(seq: int, event_type: str, submission_id: str, payload: Mapping[str, object],
          prev_hash: str) -> str:
    """sha256 over the canonical JSON of the event's chained fields (sort_keys → stable)."""
    blob = json.dumps(
        {"seq": seq, "event_type": event_type, "submission_id": submission_id,
         "payload": payload, "prev_hash": prev_hash},
        sort_keys=True, ensure_ascii=False, separators=(",", ":"),
    )
    return hashlib.sha256(blob.encode("utf-8")).hexdigest()

@dataclass(frozen=True)
class LeaderboardEvent:
    seq: int
    event_type: EventType
    submission_id: str
    payload: Mapping[str, object]    # scores / config_version / attestation — NEVER gold
    prev_hash: str

    def content_hash(self) -> str:
        return _hash(self.seq, self.event_type.value, self.submission_id, self.payload, self.prev_hash)

    def as_dict(self) -> dict[str, object]:
        return {"seq": self.seq, "event_type": self.event_type.value,
                "submission_id": self.submission_id, "payload": dict(self.payload),
                "prev_hash": self.prev_hash}

class LeaderboardStore:
    """Append-only, content-hash-chained JSONL event log. No update/delete (event-sourced)."""
    def __init__(self, path: str | Path) -> None:
        self.path = Path(path)

    def events(self) -> list[LeaderboardEvent]:
        if not self.path.exists():
            return []
        out: list[LeaderboardEvent] = []
        for line in self.path.read_text(encoding="utf-8").splitlines():
            if not line.strip():
                continue
            d = json.loads(line)
            out.append(LeaderboardEvent(d["seq"], EventType(d["event_type"]),
                                        d["submission_id"], d["payload"], d["prev_hash"]))
        return out

    def append(self, event_type: EventType, submission_id: str,
               payload: Mapping[str, object]) -> LeaderboardEvent:
        bad = _FORBIDDEN_PAYLOAD_KEYS & set(payload)
        if bad:
            raise ValueError(f"held-out gold must not be stored (FR-023): forbidden keys {sorted(bad)}")
        existing = self.events()
        seq = len(existing)
        prev_hash = existing[-1].content_hash() if existing else GENESIS_HASH
        event = LeaderboardEvent(seq, event_type, submission_id, dict(payload), prev_hash)
        with self.path.open("a", encoding="utf-8") as f:    # APPEND only — never rewrites prior lines
            f.write(json.dumps(event.as_dict(), sort_keys=True, ensure_ascii=False) + "\n")
        return event

    def verify_chain(self) -> bool:
        prev = GENESIS_HASH
        for i, ev in enumerate(self.events()):
            if ev.seq != i or ev.prev_hash != prev:
                return False
            prev = ev.content_hash()
        return True
```

`leaderboard/__init__.py` exports the store API + a minimal CLI `main`:

```python
from __future__ import annotations
import sys
from collections.abc import Sequence
from pii_anon_datasets.leaderboard.store import (
    EventType, GENESIS_HASH, LeaderboardEvent, LeaderboardStore,
)
__all__ = ["EventType", "GENESIS_HASH", "LeaderboardEvent", "LeaderboardStore", "main"]

def main(argv: Sequence[str] | None = None) -> int:
    """Minimal leaderboard CLI (wires the S5-05 `pii-anon leaderboard` verb). `verify <log>`."""
    args = list(sys.argv[1:] if argv is None else argv)
    if len(args) >= 2 and args[0] == "verify":
        ok = LeaderboardStore(args[1]).verify_chain()
        print("chain OK" if ok else "chain BROKEN", file=sys.stderr)
        return 0 if ok else 1
    print("usage: pii-anon leaderboard verify <log.jsonl>", file=sys.stderr)
    return 2
```

**Load-bearing invariants:** (1) **append-only** — only `append` writes (mode `"a"`); no
update/delete/setitem API. (2) **no held-out gold** (FR-023) — `append` rejects the forbidden payload
keys. (3) **hash chain** (NFR-014) — `prev_hash` links each event; `verify_chain` recomputes + detects
tampering. (4) **deterministic** (AX-002) — `seq`-ordered, canonical-JSON hashing, NO clock/RNG;
re-appending the same events yields identical hashes. (5) **pure-stdlib** (NFR-004; AST guard — and note
NO `time`/`datetime`).

### Load-bearing-invariant audit (security-sast crux: held-out store must NOT leak gold)

- **append-only:** `LeaderboardStore` exposes only `events`/`append`/`verify_chain`; runtime introspection
  on instance + class finds **zero** of `{update, delete, remove, pop, set, edit, mutate, replace,
  __setitem__, __delitem__}`. `append` opens the log in mode `"a"` (verified by source + by the
  grow-and-unchanged-first-line assertion). A second append `startswith` the prior bytes and the first
  line is byte-identical → prior events are never rewritten/removed (event-sourced).
- **no held-out gold (FR-023):** `append` computes `_FORBIDDEN_PAYLOAD_KEYS & set(payload)` and raises
  `ValueError` on any of `{gold, gold_labels, held_out, held_out_labels, answers, ground_truth}`; direct
  audit confirms the rejected append writes **no file** (leaves no trace). The store records
  scores/config_version/attestation/provenance only.
- **hash chain (NFR-014):** each event's `prev_hash` == the prior event's `content_hash()`; the first ==
  `GENESIS_HASH` (`"0"*64`, confirmed 64 zeros). `verify_chain()` recomputes `seq` monotonicity + every
  link and returns `False` after a single persisted line is mutated (test #4 + #7 both exercise tamper
  → fail).
- **deterministic (AX-002):** ordering is the monotonic `seq`; hashing is canonical JSON (`sort_keys=True`,
  `separators=(",",":")`). Direct audit: two fresh logs built from the same 3 events (including a
  *caller-supplied* `ts` payload field) produce a **byte-identical** log sha256 (`5daef8cf…` == `5daef8cf…`)
  and identical chain hashes — proving NO clock/RNG is generated in-module (a timestamp is caller data).
- **pure-stdlib (NFR-004):** AST guard passes — `store.py` imports only `hashlib`, `json`,
  `collections.abc`, `dataclasses`, `enum`, `pathlib`; none of `{random, time, uuid, datetime, secrets}`.
  `__init__.py` adds only `sys` + `collections.abc` + the first-party store re-export.
- **CLI wiring (S5-05 seam):** `leaderboard.main(["verify", <log>])` → `0` ("chain OK") on an intact log,
