        raise RuntimeError("Parquet export needs the 'distribution' extra: pip install pii-anon-datasets[distribution]") from e

    # regulatory_domains blob (the gov-02 fix).

    pa, pq = _require_pyarrow()
    # STREAM: accumulate rows into batches of batch_size, write with a pq.ParquetWriter (fixed schema

**Streaming (load-bearing):** `export_parquet` MUST consume `records` as an iterator and write via a
`ParquetWriter` in batches — do NOT `list(records)` the whole corpus (the old script's blowup). Test #4
passes a one-shot generator. **gov-02:** the regime columns come from `as_columns` (5 typed `reg_*`
columns); there is NO `regulatory_domains` blob column. **Lazy import:** `import pyarrow` only inside
`_require_pyarrow`; `import pii_anon_datasets.distribution` succeeds without pyarrow.

### Determinism note (pyarrow metadata caveat)

Byte-identical Parquet is **not** a stable contract: `pq.ParquetWriter` stamps the running pyarrow
library version (and `created_by`) into the file footer's key/value metadata, so two runs differ in
raw bytes even with identical logical content. Test #5 therefore asserts determinism over the
**logical table** — `table_a.schema.equals(table_b.schema)` **and** `table_a.equals(table_b)`
(schema + column data) — rather than raw bytes. Inputs to that determinism are themselves
deterministic: column order is fixed (record fields in record order, then the ordered `REGIMES`
`reg_*` columns appended last), and nested blocks are JSON-encoded with `sort_keys=True,
ensure_ascii=False` so dict-key ordering can't perturb the encoded string. No clock/RNG is touched
(AX-002-adjacent). This matches §6 test #5's explicit "compare the table contents not raw bytes".
