## 7. Acceptance criteria (Given/When/Then from FR-010)

> **Given** a consumer-supplied adversary object exposing `adversary_id`, `deterministic`, and `attack(targets, candidates, candidate_set_size)`,
> **When** the scoring core type-checks it against the `Adversary` Protocol,
> **Then** it is accepted as a pluggable adversary and its `adversary_id` is available for version-pinning ("vs adversary@version").
> **And Given** the tier3 corpus substrate, **When** `assemble_paired_set` runs, **Then** it deterministically yields aligned `(targets, candidates)` with `target_id == persona_id` ground-truth links and `|C|` honored.
> **Negative test**: an object missing any of the three members is NOT an `Adversary` (isinstance False); `assemble_paired_set` skips records lacking the tier3 substrate.

## 8b. Implementation spec (authoritative — build to this)

Pure-stdlib (NFR-004). Frozen dataclasses. Type hints everywhere; `ruff`/`mypy --strict` clean.

```python
# scoring/adversary/base.py
ADVERSARY_PORT_VERSION = "adversary-port-v1"

@dataclass(frozen=True)
class Persona:                      # the REAL side
    persona_id: str                 # == record_id (stable)
    record_id: str
    quasi_identifiers: tuple[tuple[str, str], ...]   # ((entity_type, value), ...) sorted
    behavioral_signals: dict        # tier3_evaluation.behavioral_signals (read-only, GOLD)
    source_text: str                # original real text

@dataclass(frozen=True)
class Target:                       # the PSEUDONYMOUS side the adversary attacks
    target_id: str                  # == persona_id of its true source (ground-truth link)
    anonymized_text: str            # e.g. context_preservation.anonymized_pseudonymized
    observed_signals: dict          # RE-EXTRACTED from anonymized_text via signals.py — NOT gold

@dataclass(frozen=True)
class Guess:
    target_id: str
    guessed_persona_id: str | None  # None == abstain (excluded from precision denominator)
    score: float                    # similarity/confidence for ranking

@runtime_checkable
class Adversary(Protocol):
    adversary_id: str               # version-pinned, e.g. "offline-deterministic-v1"
    deterministic: bool
    def attack(self, targets: Sequence[Target], candidates: Sequence[Persona],
               candidate_set_size: int) -> list[Guess]: ...
```

                        variant="pseudonymized") -> tuple[list[Target], list[Persona]]:

### De-circularization guard (reidx-01, LOAD-BEARING)

Test #7 proves `Target.observed_signals` are RE-EXTRACTED from the anonymized text, never copied from gold.
Empirically: source `"…the T into Beacon Hill…"` → `location_signals{present:True, uniqueness:high}`; the
pseudonymized variant `"…commute downtown…"` (signal stripped) → `location_signals{present:False,
uniqueness:none}`. The assembled `Target.observed_signals != Persona.behavioral_signals`, and the gold
`Persona.behavioral_signals` retains `very_high` — the two genuinely diverge. The assembler routes the
anonymized text through `signals.extract()`, NOT a copy of `tier3_evaluation.behavioral_signals`.

### Deviations from §8b (with justification)

1. **`detect_professional_domain(text, record_domain="general")`** — the source script signature is
   `(text, record_domain)`; §8b's `extract(text)` takes text only. Added a `"general"` default so
   `extract` is a pure function of text alone (the adversary re-extracts from anonymized text and has no
   record-domain side channel — required for Test #10 purity and reidx-01). Only the domain-gated
   SOAP/legal *structural* indicator is affected (not asserted under the default); the dominant text-based
   `INDUSTRY_JARGON` detection is byte-for-byte faithful.
2. **Type aliases instead of bare `dict`** — §8b literally writes `behavioral_signals: dict` /
   `observed_signals: dict`. To satisfy the DoD §10 `mypy --strict` gate, introduced
   `SignalsBlock = dict[str, object]` (the JSON-shaped signals block) and `Record = dict[str, Any]`
   (a loaded corpus record). Semantically identical to §8b's intent; strict-clean.
3. **`ruff format --check` not applied** (see Lint gates above) — informational only; no format gate exists
   and reformatting only owned files would break house-style consistency.
