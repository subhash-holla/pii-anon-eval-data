## 2. Goal

Turn the offline adversary's `Guess`es into the **headline measured RRS** (FR-007): run an `Adversary`
over assembled `(targets, candidates, |C|)`, count correct re-links, compute empirical re-id **recall
and precision with Wilson CIs** (on integer counts), and emit `RRS = 1 − recall×precision` wrapped in
the existing `RRSResult` value object so the **non-strippable anti-anonymity caveat (FR-009) travels
with the number**. `|C|` is a stated parameter. This is the M6-closing headline metric for DC-07.

## 8b. Implementation spec (authoritative)

Pure-stdlib. Reuse `stats.intervals.wilson_interval` (integer-guarded) + the S1 `RRSResult`.

```python
@dataclass(frozen=True)
class MeasuredRRS:
    rrs: RRSResult                # S1 value object — carries the non-strippable caveat (FR-009)
    reid_recall_ci: Interval      # wilson_interval(correct, n_targets, confidence)
    reid_precision_ci: Interval   # wilson_interval(correct, n_guesses, confidence)
    correct: int
    n_targets: int
    n_guesses: int                # non-abstain guesses
    candidate_set_size: int
    adversary_id: str
    deterministic: bool
    reid_provenance: object | None = None   # ReidProvenance attaches in S3-08 (forward seam)
    def as_dict(self) -> dict:
        # MUST nest self.rrs.as_dict() so the anti-anonymity caveat is ALWAYS serialized (gov-01)
        ...

def score_reidentification(adversary, targets, candidates, candidate_set_size,
                           confidence: float = 0.95, reid_provenance=None) -> MeasuredRRS:
    guesses = adversary.attack(targets, candidates, candidate_set_size)
    committed = [g for g in guesses if g.guessed_persona_id is not None]
    n_targets = len(targets)
    n_guesses = len(committed)
    # ground-truth link: assemble_paired_set set target_id == true persona_id
    correct = sum(1 for g in committed if g.guessed_persona_id == g.target_id)
    recall = correct / n_targets if n_targets else 0.0
    precision = correct / n_guesses if n_guesses else 0.0
    rrs = RRSResult.from_attack(recall, precision, candidate_set_size,
                                adversary.adversary_id, adversary.deterministic)
    return MeasuredRRS(
        rrs=rrs,
        reid_recall_ci=wilson_interval(correct, n_targets, confidence),
        reid_precision_ci=wilson_interval(correct, n_guesses, confidence),  # n=0 → intervals.py edge
        correct=correct, n_targets=n_targets, n_guesses=n_guesses,
        candidate_set_size=candidate_set_size,
        adversary_id=adversary.adversary_id, deterministic=adversary.deterministic,
        reid_provenance=reid_provenance,
    )
```
**Edge case:** `wilson_interval(0, 0)` — read `stats/intervals.py` for its n=0 behavior; if it raises, guard by returning a sentinel `Interval(point=0.0|nan, low=0.0, high=1.0, n=0, method="wilson", confidence=...)` and document it. Do NOT silently fabricate a CI.
**Do NOT** alter the frozen `RRSResult` contract (S1). The caveat stays mandatory + non-defaulted.

### wilson_interval(0,0) edge (§8b) — how it was handled
`stats/intervals.py::wilson_interval` already guards n=0 **internally**: it returns the documented
sentinel `Interval(point=nan, low=0.0, high=1.0, n=0, method="wilson", confidence)` (does NOT raise).
So `score_reidentification` simply passes the integer counts straight through — recall/precision are
defined as `0.0` when their denominator is 0, and the CI is `intervals.py`'s own n=0 sentinel. **No CI is
fabricated.** Pinned by `test_fr_007_perfect_attack_rrs_zero_and_no_commit_rrs_one` (asserts
`precision_ci.n == 0`, `low == 0.0`, `high == 1.0`, `method == "wilson"`). reidx-02 integer guard
(fractional → `TypeError`) pinned by `test_fr_007_reidx02_fractional_count_raises`.
