## 2. Goal

Implement the **deterministic offline re-identification adversary** — the *headline* RRS attacker
(design revision #1, reidx-01): no RNG, no network, no LLM, fully reproducible. It links pseudonymous
`Target`s to real `Persona` candidates using only what SURVIVED anonymization (the re-extracted
`observed_signals` + quasi-identifier tokens still present in `anonymized_text`), and emits ranked
`Guess`es. Also ships the FR-010 **distractor-augmented (web-like auxiliary)** variant. The measured
RRS *scoring* (recall/precision/RRS + CIs) is S3-04; this story is the adversary it runs.

## 8b. Implementation spec (authoritative)

Pure-stdlib. Frozen config. Full type hints. No RNG/clock/network/LLM (that's what "offline deterministic" means).

```python
OFFLINE_ADVERSARY_VERSION = "offline-deterministic-v1"
DISTRACTOR_CORPUS_ID = "web-like-distractors-v1"

@dataclass(frozen=True)
class OfflineAdversaryConfig:
    feature_weights: tuple[tuple[str, float], ...]   # sorted; per signal-category weight
    score_threshold: float                            # min top-sim to commit a guess (else abstain)
    tie_break: str = "lexicographic_persona_id"
    distractor_corpus_id: str | None = None

DEFAULT_OFFLINE_CONFIG = OfflineAdversaryConfig(
    feature_weights=(("interest_topics",1.0),("location_signals",1.0),("personal_anecdote",1.0),
                     ("professional_domain",1.0),("temporal_patterns",1.0),("writing_style",1.0),
                     ("quasi_identifier_token",2.0)),   # surviving QI tokens weigh double
    score_threshold=0.0,   # 0.0 == always commit the top candidate; raise to force abstention
)

class OfflineDeterministicAdversary:
    deterministic = True
    def __init__(self, config: OfflineAdversaryConfig = DEFAULT_OFFLINE_CONFIG) -> None:
        self._config = config
        self.adversary_id = (OFFLINE_ADVERSARY_VERSION if config.distractor_corpus_id is None
                             else f"{OFFLINE_ADVERSARY_VERSION}+distractor:{config.distractor_corpus_id}")
    def attack(self, targets, candidates, candidate_set_size) -> list[Guess]: ...
```

**Algorithm (deterministic):** for each `Target t`:
1. Build a feature multiset from `t.observed_signals`: for each of the 6 categories, weight =
   `signals.UNIQUENESS_WEIGHT[cat.uniqueness] * config.feature_weights[cat]` when `present`; plus the
   set of QI-token strings still appearing in `t.anonymized_text` (weighted by the `quasi_identifier_token` weight).
2. For each `Persona c` in the (optionally distractor-augmented) candidate pool truncated to
   `candidate_set_size`, compute a deterministic **weighted Jaccard** similarity `sim(t,c)` over the
   same feature catalogue derived from `c.behavioral_signals` + `c.quasi_identifiers`.
3. Rank candidates by `(sim desc, persona_id asc)` — the lexicographic tie-break makes ranking total
   and input-order-independent.
4. Emit `Guess(target_id=t.target_id, guessed_persona_id=(top.persona_id if top_sim>=threshold else None), score=top_sim)`.

**Distractor variant:** when `config.distractor_corpus_id` is set, `attack` augments `candidates`
with a deterministic set of distractor `Persona`s (the caller passes them, OR they're assembled
elsewhere — for THIS story, accept an optional pre-supplied distractor list via the candidate pool
and just version-stamp the `adversary_id`; the assembly of distractors from non-candidate tier3
records is S3-01's `assemble_paired_set` distractor mode / a later wiring). Effect: |C| grows,
precision drops as decoys compete. Keep it deterministic.

No `import random`, `time`, `datetime`, `uuid`, `secrets`, or any network/LLM module.
