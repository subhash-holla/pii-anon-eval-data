## 2. Goal

Implement the anonymization scorer (DC-06): given a system's anonymized text + the assembled
adversary inputs, emit a **privacy-utility Pareto point** — residual re-identification risk (the
privacy axis, reusing the S3-04 measured-attack machinery → a `MeasuredRRS`) AND downstream utility
(the utility axis, a pinned deterministic `token-preservation-v1` probe) — **as two separate nested
value objects that no code path can fuse into a single scalar** (FR-006 "never merged into one
number"; NFR-005/AX-004). This is where the anon-family lives, structurally separate from pseudonymization (S3-07).

## 8b. Implementation spec (authoritative)

Pure-stdlib. Frozen. No RNG/clock. Reuse S3-04 `MeasuredRRS`/`score_reidentification` for the privacy axis.

```python
UTILITY_PROBE_VERSION = "token-preservation-v1"
PARETO_SEPARATION_NOTE = ("Privacy and utility are reported as a Pareto point and are NEVER "
                          "combined into a single de-identification score (NFR-005 / AX-004).")

@dataclass(frozen=True)
class UtilityScore:
    utility: float                              # [0,1]; higher = more downstream utility retained
    components: tuple[tuple[str, float], ...]   # named sub-scores (transparent)
    probe: str = UTILITY_PROBE_VERSION

def score_utility(original_text: str, anonymized_text: str,
                  utility_metrics: dict | None = None) -> UtilityScore:
    # primary component = non-PII token-preservation Jaccard(original, anonymized);
    # secondary = (1 - information_loss_ratio) and coherence booleans (0/1) if utility_metrics given.
    # utility = fixed weighted combination of the components (frozen weights). Deterministic, stdlib.

@dataclass(frozen=True)
class ParetoPoint:
    residual_risk: MeasuredRRS    # privacy axis (carries the anti-anonymity caveat — FR-009)
    utility: UtilityScore         # utility axis
    variant: str                  # which anonymized_* variant was scored
    note: str = PARETO_SEPARATION_NOTE
    # DELIBERATELY: no .combined / .overall / .deid / .score property; no __float__.
    def __post_init__(self) -> None:
        if not self.note.strip(): raise ValueError("Pareto separation note required")
    def as_dict(self) -> dict:
        return {"privacy": self.residual_risk.as_dict(),   # two SEPARATE sub-objects
                "utility": {"utility": self.utility.utility, "components": [...], "probe": self.utility.probe},
                "variant": self.variant, "note": self.note}

def score_anonymization(adversary, targets, candidates, candidate_set_size, *,
                        original_text, anonymized_text, variant,
                        utility_metrics=None, confidence: float = 0.95) -> ParetoPoint:
    residual = score_reidentification(adversary, targets, candidates, candidate_set_size, confidence)
    util = score_utility(original_text, anonymized_text, utility_metrics)
    return ParetoPoint(residual_risk=residual, utility=util, variant=variant)
```

**Why this CANNOT merge (NFR-005, load-bearing):** the two axes are nested objects of *different
types* (`MeasuredRRS` vs `UtilityScore`); there is no arithmetic field combining them, no `__float__`,
no `overall`/`score`/`deid`/`combined` attribute. Test #4 asserts this both by `hasattr`/introspection
AND by a source grep for forbidden merged-metric names. (The frozen weights INSIDE `utility` combine
*utility components* only — that is fine; what's forbidden is combining the privacy and utility AXES.)
