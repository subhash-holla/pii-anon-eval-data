## 2. Motivation (§1) — why NOW, verified against code (2026-06-01)

The gap CAP-02 closes is the **wiring** between a v2.0.0 corpus and a mature engine, done to an academic-soundness bar — and that wiring is not merely missing, it is **actively wrong** in three independent, code-verified ways:

1. **Drift — `pii-rate-elo` cannot honestly read the current corpus.** The converter `datasets/converters/pii_anon_eval.py` hard-pins `num_records=159891` (L93), `license="CC-BY-4.0"` (L221), `citation="…v1.3.0"` (L222); `schema.py` self-identifies `version: str = "1.3.0"` (L137). The live artifact is **v2.0.0 / 575,604 / CC0 / `annotations`**. A consumer reproducing from this metadata gets the wrong version, ~3.6× the wrong record count, the wrong license, a stale citation. *Verified nuance:* the row parser already tolerates `annotations` with a `labels` fallback (`schema.py:349`) — so the hard, uncaveated drift is the **declared provenance (count + version pins)**, not field-reading. (Verified this session: pins present at the cited lines.)
2. **No powered / pre-registered / reproducible path.** pii-rate-elo's only subsetting knob is naive head-truncation — `if max_samples is not None and count >= max_samples: break` (converter L82–84; loader L73; threaded through `cli.py`). That returns the first N rows in file order — it cannot hit a per-cell target, cannot stratify by (language × entity_type × domain), and cannot report a shortfall. eval-data's `stats/power.py` is a different species: NIST/SEMATECH §7.2.4.2 `required_n()` with tier targets **derived, not hand-typed** (verified this session: `CRITICAL (0.99, 0.005)→1522`, `STANDARD (0.98, 0.010)→753`, `LONG_TAIL (0.95, 0.03025)→200`), a parallel re-id ladder (`reid_required_n(0.30,0.030)→897`, `(0.10,0.030)→385` pairs), and `PowerClass ∈ {WELL_POWERED, UNDER_POWERED, EMPTY}` feeding a `PowerMatrix.verdict()` SMALL/ADEQUATE/LARGE. None of this is reachable through pii-rate-elo's seam. The frozen 730-cell lattice the sample targets is committed at `47c3a8f`.
3. **Fabricated statistics on the run path.** `cli.py:242` instantiates `SignificanceTester()`. Its "bootstrap" CI adds Gaussian noise to a point estimate — `se = metric_value*(1-metric_value)/100` with a hardcoded `100` (not n), then `np.random.normal(0, se)` (verified this session: `significance.py:205-206`); its "McNemar" never sees a discordant-pair count — `n_approx = 100`, `z_stat = difference*sqrt(n_approx)/0.05`, `pooled_sd = 0.1` (verified: L271-281). Meanwhile `eval-data/stats/paired.py` implements the *correct* paired stack (exact binomial McNemar, Edwards continuity-corrected χ², a real paired bootstrap resampling pair indices with a seeded RNG) and `stats/intervals.py` the integer-guarded Wilson/Clopper-Pearson CIs — **one repo over and bypassed**. A single reviewer who diffs the two files rejects the methodology outright.

**Macro context (why the bar is non-negotiable).** (a) The 2026 leaderboard consensus is "read the CI column, not the rank" — a benchmark whose thesis is *distrust of single numbers* cannot ship a number without a CI. (b) Synthetic benchmarks demonstrably **over-estimate** de-identification (SPY, NAACL SRW 2025; Tonic.ai 2026) — the non-strippable synthetic-only caveat is a peer-review precondition (enforced by construction: `ReidProvenance.__post_init__` raises on empty caveat; AX-001/003). (c) **Reproducibility, not pre-registration, is the active NLP norm** (ReproNLP'26; REFORMS) — CAP-02 treats seeded/byte-reproducible-from-manifest as table stakes and pre-registration as opt-in rigor for the one citation-chasing persona.

**Hard preconditions CAP-02 commits to (all currently open):** (1) route the run path through the audited `eval-data/stats` core (quarantine `analysis/significance.py`); (2) reconcile the dataset seam to v2.0.0 / 575,604 / CC0 / `annotations`; (3) add the powered, lattice-stratified sampler emitting the `PowerMatrix` verdict + per-cell shortfall as a *report artifact*; (4) bind "sample" to the cost-bound tracks, detection full-corpus-audited by default, FULL = citable.
